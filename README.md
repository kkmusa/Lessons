# Уроки — проект для Android Studio

Полный исходный код приложения «Уроки», версия 1.2.0: ученики, тарифы, занятия, календарь, оплаты, долги/авансы, аналитика, резервные копии и Android-напоминания. Интерфейс — HTML/CSS/JavaScript внутри локального Android WebView; приложение работает без сервера и интернета.

## Открыть и запустить

1. Распакуйте **весь ZIP** в отдельную папку.
2. В Android Studio выберите **Open** и откройте папку, в которой лежат `settings.gradle`, `build.gradle` и `gradlew`. Не выбирайте вложенную папку `android`.
3. Дождитесь **Gradle Sync**. При первом открытии нужен интернет для загрузки Gradle и зависимостей.
4. В **SDK Manager** установите **Android SDK Platform 35** и **Android SDK Build-Tools 35.0.0**, если Studio предложит.
5. В настройках Gradle выберите встроенный **JDK 21** или JDK 17 (не JRE). Android Studio Meerkat 2024.3.1 или новее с поддержкой Android Gradle Plugin 8.9.2.
6. Выберите модуль **app**, подключите телефон с включённой отладкой по USB или создайте эмулятор Android 8.0+ и нажмите **Run ▶**.

`local.properties` с путём к SDK Android Studio создаст для вашего компьютера. Этот файл не включён в архив. Gradle Wrapper для Windows, Linux и macOS включён; отдельно устанавливать Gradle не нужно. Node.js для сборки Android не требуется.

## Сборка через терминал

Windows:

```bat
gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

macOS / Linux:

```sh
chmod +x gradlew
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

APK появится в `android/build/outputs/apk/debug/app-debug.apk`.

## Существующее приложение и данные

Debug-сборка называется **«Уроки · разработка»** и имеет отдельный applicationId `ru.uroki.app.dev`. Она устанавливается **рядом** с ранее скачанным APK `ru.uroki.app`, у неё своя база данных. Чтобы перенести данные, в старом приложении откройте **Данные → Сохранить в файл**, затем восстановите этот файл в версии для разработки.

Приватного ключа подписи ранее выпущенных APK в архиве и GitHub **нет**. Android Studio подписывает debug-сборку своим локальным ключом. Для обновления старого `ru.uroki.app` нужен именно исходный ключ; другой ключ не позволит установить обновление поверх него. Не удаляйте старое приложение без резервной копии.

Release-вариант сохраняет applicationId `ru.uroki.app` и не содержит настроенной подписи. Для собственной подписанной сборки: **Build → Generate Signed App Bundle or APK**, затем выберите ваш keystore. Ключи и пароли нельзя добавлять в GitHub.

## Где что редактировать

| Файлы | Назначение |
| --- | --- |
| `public/app.js` | Экраны, формы и действия пользователя |
| `public/model.js` | Баланс, стоимость, аналитика и отметка «Проведено» |
| `public/style.css`, `public/index.html` | Оформление и HTML |
| `android/src/ru/uroki/app/MainActivity.java` | WebView, файлы, обмен и разрешения Android |
| `android/src/ru/uroki/app/Reminders.java` | Планирование и показ уведомлений |
| `android/src/ru/uroki/app/ReminderClock.java` | Расчёт времени напоминания |
| `android/AndroidStudioManifest.xml` | Манифест сборки в Android Studio |
| `android/res/` | Иконки Android |
| `android/build.gradle` | Версии приложения, SDK и варианты сборки |
| `test/android-junit/` | JUnit-тесты для Gradle / Android Studio |
| `test/model.test.js` | Тесты расчётов JavaScript |

При сборке Gradle сам копирует содержимое `public/` в assets приложения. Не редактируйте сгенерированные файлы в `android/build`.

Манифест `android/AndroidManifest.xml` и скрипты `scripts/` оставлены для исходного облачного способа сборки без Gradle; он описан в `docs/CLOUD_BUILD.md`. При изменении Android-разрешений/компонентов учитывайте оба манифеста.

## Проверки и веб-разработка (необязательно)

Для проверки расчётов и разработки интерфейса отдельно от Android нужен Node.js 24:

```sh
npm run check
npm test
npm start
```

Браузерная версия запускается на порту 3000, её база не синхронизируется с Android.

## Уведомления

В Android-приложении нажмите **Настроить уведомления** и разрешите уведомления и точные будильники. Напоминания планируются за 10 минут до урока; отмена/завершение занятия убирает напоминание. Для Android 13+ требуется разрешение уведомлений, на Android 12+ — доступ к точным будильникам. Ограничения батареи и принудительная остановка могут влиять на доставку. Интеграция с островком HyperOS не реализована.

Данные хранятся локально. Перед удалением приложения или сменой телефона сохраните резервную копию. В архиве нет пользовательской базы, личных данных и ключей.
