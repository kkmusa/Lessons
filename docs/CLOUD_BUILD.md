# Уроки

Личный журнал репетитора на русском языке. Android-приложение (APK) с локальным интерфейсом WebView; сервер, аккаунт и интернет на телефоне не нужны. Android 8.0+ с актуальным Android System WebView.

- Ученики, почасовой или фиксированный тариф, длительность.
- Начальный долг или аванс на заданную дату.
- Занятия: проведено, запланировано, отменено; шахматка по месяцам.
- Оплаты и редактирование истории, итоги для отправки ученику через Android.
- Заработок, полученные деньги, время и число занятий за неделю, месяц и весь период.
- JSON-копии через системный выбор файлов Android.

Баланс = начальный баланс + проведённые занятия − полученные оплаты. Плюс означает долг ученика, минус — его аванс. Тариф фиксируется в каждом занятии, изменение тарифа ученика не меняет историю. Начальная дата не должна быть позже уже внесённых операций. Начальный остаток не считается заработком. Будущие занятия нужно планировать. Аналитика заканчивается сегодняшним днём, неделя начинается в понедельник.

Пример: аванс 12000 ₽, 7 занятий по 1500 ₽, новая оплата 5000 ₽ → аванс 6500 ₽.

## Разработка в облаке

Уже используйте имеющийся checkout `/workspace/Lessons`. Новые worktree не нужны: облачная задача изолирована.

Нужны Node.js 24, Python 3, Java 21 runtime и keytool. В текущей среде они установлены. Зависимостей npm у приложения нет.

```sh
cd /workspace/Lessons
python scripts/setup_android.py
npm run check
npm test
npm run android:test
npm run android:build
```

Подготовка загружает Android platform 35 и Build Tools 35.0.0 из dl.google.com и Eclipse Java Compiler 3.40.0 из Maven Central. Проверяет контрольные суммы, не отключает TLS. Android SDK лежит в `/workspace/android-sdk`, компилятор — `/workspace/tools/ecj.jar`. Использование Android SDK регулируется лицензией Google Android SDK.

Результат: `dist/uroki.apk`. Локальный ключ разработки хранится вне checkout: `/workspace/.uroki/development.keystore`. Сохраните этот ключ для обновлений без удаления приложения. Это development-сборка для личной установки, не релиз для Google Play. Не публикуйте ключ. Для установки откройте APK на телефоне и разрешите установку этому файловому менеджеру/браузеру.

Для просмотра интерфейса и разработки: `npm start` (порт 3000). Проверка HTTP: `curl -f http://localhost:3000/`. Веб-версия отдельно хранит свою базу в браузере; она не синхронизируется с Android.

## Данные и ограничения

Не удаляйте приложение без резервной копии: данные только на телефоне. Нет облачной синхронизации и автоматических резервных копий. Перед восстановлением файла экспортируйте текущую базу; импорт заменяет её целиком. Итоги — текстовый расчёт для ученика, не юридический счёт и не фискальный чек.

Проверены расчёты (5 тестов), мобильный браузерный сценарий: создание ученика, семь занятий, платёж, баланс, итоговый расчёт, шахматка, перезагрузка с сохранением данных, аналитика. APK собирается и проходит apksigner verify. Запуск APK на реальном Android и системный обмен файлами требуют проверки на устройстве; Android-эмулятор в этой среде отсутствует.


## Обновление 1.1.0

- Крупная кнопка добавления занятия только на главной странице.
- Календарь показывает все дни месяца без горизонтальной прокрутки; под ним список с датами, временем, учениками и статусами. Выбор дня фильтрует список, «Весь месяц» сбрасывает фильтр. Существующие занятия можно редактировать из списка.
- В аналитике по умолчанию общие показатели, выбор ученика фильтрует суммы, платежи, количество, время и график.
- Android-напоминания за 10 минут до запланированного занятия: AlarmManager, канал высокой важности, восстановление после перезагрузки/обновления/смены времени. Отмена, удаление и изменение занятия обновляют будильник. Если до занятия меньше 10 минут, напоминание планируется сразу. Прошедшие занятия не напоминаются.
- Разрешите уведомления и точные будильники кнопкой «Настроить уведомления». Без разрешения точных будильников Android может задержать напоминание; без разрешения уведомлений оно не появится. Принудительная остановка приложения и ограничения производителя могут блокировать доставку до следующего открытия. Часы и часовой пояс используются текущие на телефоне.
- Поддержка «островка» оболочки производителя не заявлена. Используются стандартные уведомления Android.

APK 1.1.0 имеет тот же package и ключ подписи, что 1.0.0: устанавливайте поверх старой версии, не удаляя её. Перед обновлением рекомендуется резервная копия.

Дополнительно проверены на ширине 360px все 31 день октября, выбор дня, список с временем, редактирование/отмена, отсутствие создания вне главной, общая/индивидуальная аналитика и payload Android-моста при планировании/отмене. `npm run android:test` проверяет фактический Java-код расчёта времени напоминаний и смену часового пояса. Фактическая доставка уведомления на Android-устройстве ещё не проверена.

## Обновление 1.2.0

На главной появился блок «Сегодня и неотмеченные»: плановые занятия за сегодня и прошлые дни, чтобы прошедший неотмеченный урок не терялся. Кнопка «✓ Проведено» одним нажатием меняет статус существующего занятия, начисляет его сохранённую стоимость, обновляет аналитику и отменяет напоминание. Повторное начисление невозможно: отдельная финансовая операция не создаётся. Кнопка доступна также у существующих занятий в календаре и карточке ученика. Для будущих дат она скрыта. Ошибочную отметку можно исправить через редактирование занятия, вернув статус «Запланировано».

Проверено: 7 модельных тестов, мобильный сценарий на 360px (просроченное занятие на главной, нажатие без диалога, сумма, список напоминаний Android-моста, календарь и аналитика, исправление через редактирование, сохранение после перезапуска). Нативная доставка уведомлений по-прежнему требует проверки на Android.
